## Этап 1b — курсы, каталог, плеер (18.11.2026)

**Сделано**

- Каталог из официальных плейлистов университетов (`npm run catalog`): 25 курсов в 4 треках.
  - Трек 1 с настоящими ID и длительностями видео: CS50x (лекции 0–6 — русская озвучка,
    остальное и семинары — оригинал), CS50P, MIT 18.01 + разборы задач 18.01SC, MIT 18.06SC
    с разборами задач, Yale PHYS 200 (механика → термодинамика), MIT 8.01SC, MIT 6.042J, Stanford CS106B.
  - Треки 2–4 — кандидаты с проверенными плейлистами и оценкой часов; импорт — кнопкой в приложении.
- База данных: курсы, видео, прогресс, закладки; каталог загружается из `seed/` при старте.
- Страница «Мои курсы»: коллекции, фильтры по треку, предмету, университету и уровню.
- Страница курса: программа с лекциями и практикой, пререквизиты, источник, лицензия, перевод.
- Плеер «Учёба»: официальный YouTube-плеер, продолжение с места остановки, отметка «просмотрено»
  с 90%, русские субтитры по умолчанию, скорость, горячие клавиши, закладки, фокус-режим,
  понятные ошибки с кнопкой «Открыть на YouTube».
- Главная: «Продолжить обучение» с последней лекцией и ряд «Мои курсы».
- 93 теста: клиент YouTube API, длительности, импорт плейлистов, загрузка каталога, правила
  прогресса, API, фильтры каталога, форматирование.

**Как проверить**

```bash
npm run dev
```

http://127.0.0.1:5180/courses → курс → «Начать курс». Посмотри пару минут, закрой вкладку, открой
лекцию снова — она продолжится с того же места, а курс окажется в «В процессе».

**Приёмка (проверено во встроенном браузере)**

- Лекция 18.06 открыта, перемотана на ~3:00, страница закрыта и открыта снова — плеер стартовал
  со 182-й секунды; прогресс курса изменился; курс сам переехал в «В процессе».
- Русские субтитры (автоперевод YouTube) включаются программно; для русской озвучки они выключены.
- B добавляет закладку, F включает фокус-режим; на ширине телефона страницы не уезжают вбок.

**Решения**

- Физика начинается с механики (Yale PHYS 200), сначала ищем русские переводы — по уточнению.
- Перевод CS50P не взят: нет указания автора, лекцию 0 нельзя встроить (решение пользователя).
- Видео хранятся по YouTube ID, курсы ссылаются на них через отдельную таблицу: одно видео может
  быть в нескольких курсах, а прогресс переживает пересборку каталога.
- У MIT 18.01 разборы задач расставлены между лекциями пропорционально — примерно по темам.
- Горячие клавиши работают, пока курсор не над видео; над видео действуют клавиши самого YouTube.

**Известное**

- Основной файл приложения ~700 КБ (217 КБ в сжатом виде): можно разделить по страницам позже.
- У 8.01SC часть видео без номера недели собрана в «Разборы задач» и «Дополнительно».

**Как проверить**


Открой http://127.0.0.1:5180/dev/ui и http://127.0.0.1:5180/dev/home (или меню аватара).

**Утверждено**

- Витрина и пример главной приняты без правок.
- Шрифт заголовков и логотипа — **Unbounded**. Второй кандидат (Montserrat) и переключатель убраны.

**Решения**

- Пакет `next-themes`, который shadcn ставит для светлой/тёмной темы, убран: тема только тёмная.
- Добавлен `tw-animate-css` — плавное появление меню, окон и подсказок (с учётом настройки
  «уменьшить движение» в системе).
- Витрина и пример главной загружаются отдельно и не утяжеляют основные экраны.

**Находка для этапа 1b**

  будем брать из плейлистов официального канала MIT OpenCourseWare через YouTube API.

## Этап 0 — каркас + GitHub (18.11.2026)

**Сделано**

- Vite 8 + React 19 + React Router 8, Tailwind CSS 4 + shadcn/ui, Fastify 5, SQLite + Drizzle, zod.
- ESLint, Prettier, Vitest; CI в GitHub Actions: типы, линтер, форматирование, тесты, сборка.
- Верхнее меню из пяти разделов, фиолетово-чёрная тема, страницы-заглушки разделов.
- `GET /api/health` → `{"status":"ok"}`: заодно проверяет, что база отвечает.
- Первая миграция базы (таблица `settings`); миграции применяются при старте сервера.
- `CLAUDE.md`, `README.md`, `LICENSE` (MIT), `.env.example`.

**Как проверить**

```bash
npm run dev
```

Открой http://127.0.0.1:5180 — главная и разделы меню. Проверка сервера: http://127.0.0.1:5180/api/health.

**Решения**

- TypeScript 6.0, а не 7.0: линтер typescript-eslint пока не поддерживает седьмую версию.
- В режиме разработки интерфейс отдаёт Vite (порт 5180), а API работает на 5181; Vite сам пересылает
  запросы `/api`. В обычном запуске (`npm start`) всё работает в одном процессе на 5180.
- `.env` читается встроенной функцией Node (`process.loadEnvFile`), без пакета dotenv.
- Шрифты (Inter, Unbounded) лежат внутри приложения, а не грузятся из Google Fonts: работают офлайн.
- Классы объединяет пакет `cn` от авторов shadcn вместо `clsx` + `tailwind-merge`.
- Коммиты подписаны скрытым email GitHub (`…@users.noreply.github.com`).

**Известное**

- `npm audit` показывает уязвимости только в инструментах разработки: `picomatch` (через Vite, Vitest,
  typescript-eslint; исправленной версии пока нет) и старый `esbuild` внутри `drizzle-kit`. В само
  приложение они не попадают (`npm audit --omit=dev` — 0 уязвимостей).
