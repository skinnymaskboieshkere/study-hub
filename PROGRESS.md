## Этап 1a — дизайн-система (18.11.2026) — утверждено

**Сделано**

- Витрина `/dev/ui`: палитра и цвета треков, шрифты, кнопки, фильтры каталога, бейджи, коллекции,
  поля мастера плана, задачи, карточки курсов, баннер текущего курса, программа курса, прогресс,
  пустые состояния и ошибки, меню, подсказка, окно, уведомления, таймкоды, узлы дорожной карты.
- Пример главной по макету `/dev/home`: баннер текущего курса, «План на сегодня», «Мои курсы»,
  путь к Computer Vision. Данные примерные.
- Меню профиля под аватаром: «Настройки», «Витрина интерфейса», «Пример главной».
- Обложки курсов — настоящие превью лекций с YouTube (CS50x, CS50P, Columbia FPCV); без видео
  рисуется обложка в цвете трека.
- Тесты для форматирования времени, падежей («лекция/лекции/лекций») и ссылок YouTube с таймкодом.

**Как проверить**

```bash
npm run dev
```

Открой http://127.0.0.1:5180/dev/ui и http://127.0.0.1:5180/dev/home (или меню аватара).

**Утверждено**

- Витрина и пример главной приняты без правок.
- Шрифт заголовков и логотипа — **Unbounded**. Второй кандидат (Montserrat) и переключатель убраны.

**Решения**

- Пакет `next-themes`, который shadcn ставит для светлой/тёмной темы, убран: тема только тёмная.
- Добавлен `tw-animate-css` — плавное появление меню, окон и подсказок (с учётом настройки
  «уменьшить движение» в системе).
- Витрина и пример главной загружаются отдельно и не утяжеляют основные экраны.

**Находка для этапа 1b**

- На страницах MIT OCW (18.06SC) нет ссылок на YouTube — только файлы на archive.org. Видео MIT
  будем брать из плейлистов официального канала MIT OpenCourseWare через YouTube API.

## Этап 0 — каркас + GitHub (18.11.2026)

**Сделано**

- Vite 8 + React 19 + React Router 8, Tailwind CSS 4 + shadcn/ui, Fastify 5, SQLite + Drizzle, zod.
- ESLint, Prettier, Vitest; CI в GitHub Actions: типы, линтер, форматирование, тесты, сборка.
- Верхнее меню из пяти разделов, фиолетово-чёрная тема, страницы-заглушки разделов.
- `GET /api/health` → `{"status":"ok"}`: заодно проверяет, что база отвечает.
- Первая миграция базы (таблица `settings`); миграции применяются при старте сервера.
- `CLAUDE.md`, `README.md`, `LICENSE` (MIT), `.env.example`.

**Как проверить**

```bash
npm run dev
```

Открой http://127.0.0.1:5180 — главная и разделы меню. Проверка сервера: http://127.0.0.1:5180/api/health.

**Решения**

- TypeScript 6.0, а не 7.0: линтер typescript-eslint пока не поддерживает седьмую версию.
- В режиме разработки интерфейс отдаёт Vite (порт 5180), а API работает на 5181; Vite сам пересылает
  запросы `/api`. В обычном запуске (`npm start`) всё работает в одном процессе на 5180.
- `.env` читается встроенной функцией Node (`process.loadEnvFile`), без пакета dotenv.
- Шрифты (Inter, Unbounded) лежат внутри приложения, а не грузятся из Google Fonts: работают офлайн.
- Классы объединяет пакет `cn` от авторов shadcn вместо `clsx` + `tailwind-merge`.
- Коммиты подписаны скрытым email GitHub (`…@users.noreply.github.com`).

**Известное**

- `npm audit` показывает уязвимости только в инструментах разработки: `picomatch` (через Vite, Vitest,
  typescript-eslint; исправленной версии пока нет) и старый `esbuild` внутри `drizzle-kit`. В само
  приложение они не попадают (`npm audit --omit=dev` — 0 уязвимостей).
